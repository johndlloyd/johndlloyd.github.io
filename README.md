# johndlloyd.com

Personal site for John D. Lloyd.

## Stack

- Static HTML/CSS/JS (no Jekyll)
- Data-driven content files under `public/content/`

## Content model

- `public/content/docs.js` for top-level sections
- `public/content/projects.js` for project index + detail data
- `public/content/articles.js` for article index + detail data

## Local preview

```bash
npm run dev
```

Open `http://127.0.0.1:8788`.

## Deploy

Push updates to the branch configured as your Pages source.
